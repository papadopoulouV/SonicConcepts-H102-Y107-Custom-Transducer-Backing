# SonicConcepts-H102-Y107-Custom-Transducer-Backing
This STL file can be printed for use with the Sonic Concepts H102 and Y107 transducers and the accompanying Sonic Concepts coupling cone. This backing can be used with a motion stage for precise positioning and targeting for focused ultrasound treatments.
